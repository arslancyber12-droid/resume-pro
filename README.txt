# Vercel upload folder (v15)
Upload everything inside this folder to the ROOT of your GitHub repository (index.html, vercel.json and the api folder must be at the top).
AI key: Vercel > Settings > Environment Variables > ANTHROPIC_API_KEY (mark Sensitive), then Redeploy. Never put the key in GitHub.
Check AI: open https://YOUR-SITE/api/write  ->  {"ok":true,"ai":true} means AI is on.
